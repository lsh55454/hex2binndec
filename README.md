Hello, world.
This is a repo for converting any hex values to binary and decimals.
The python project would print the values in order.

## Usage:
```shell
python3 main.py

# Enter HEX values! Or the program will crash(><)
E8

# Output; Blank between 4 digits.
BIN: 1110 1000
DEC: 232
```

The program gets input until EOF(i.e. Ctrl+D)
Or you could let a file to be input like this:

python3 main.py < input.txt


## Requirements
Python
